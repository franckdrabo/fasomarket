2. Description of Service

FasoMarket is a mobile marketplace dedicated to buying and selling between individuals in West Africa. The Application allows users to:

  • Publish sale listings for items (clothing, shoes, electronics, home goods, etc.)
  • Search and discover items nearby
  • Communicate directly with sellers via integrated messaging
  • Rate sellers and buyers after a transaction
  • Manage listings, favorites, and profile

📌 Note: Transactions are 100% Peer-to-Peer (P2P). The buyer pays the seller directly via Mobile Money using the number shared in the conversation. FasoMarket does not mediate payments between users.
